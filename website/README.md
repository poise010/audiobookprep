# AudiobookPrep website

A complete, dependency-free marketing website for the next version of AudiobookPrep. Designed for independent narrators and audiobook producers, with a fictional guide preview, proposed memberships, a plan calculator and a dedicated `/studio/` coming-soon page.

**This directory contains the website only.** The existing `frontend/` and `backend/` application are separate and are not used, modified or started by this website. There is no AI processing, account system, payment flow, email capture or manuscript upload in this deliverable.

## Run in VS Code

Open the repository, then run in its terminal:

```sh
cd website
npm run dev
```

Open **http://localhost:4173**. Requires Node.js 20 or newer. There is nothing to install.

Or open `AudiobookPrep.code-workspace` from this directory and run the **Preview website** task.

```sh
npm run check     # JavaScript syntax, pricing/build/link tests, production build
npm run build     # Rebuild the static dist/ directory and Squarespace snippets
npm run preview   # Serve dist/ on http://localhost:4173 (stop dev first)
```

The local server listens only on the loopback interface. It is for development, not a production web server.

## What is included

- Responsive homepage, custom logo and manuscript illustration.
- Three switchable fictional guide sections and a downloadable sample.
- Monthly/yearly pricing controls with explicit annual totals.
- Word-count calculator with allowance boundaries and invalid-input feedback.
- Accessible native dialogs, FAQ disclosures, mobile navigation, keyboard focus and reduced motion.
- Future software home at `/studio/` with truthful development status.
- Locally served Manrope variable font and its SIL Open Font License.
- Squarespace page bodies, scoped embed stylesheet and code-injection snippets generated by the build.

## Change content or pricing

Edit copy in `index.html`. Update plan data in `assets/pricing.js` **and** the initial HTML prices, allowances and plan descriptions so the page still works without JavaScript. Run `npm run check` after editing. Annual billing represents 12 monthly allowances, not an annual pool. Prices are USD proposals; there is intentionally no checkout.

## Deploy

Publish the contents of `dist/` to a static host. On a GitHub-connected host use `website` as the project root, `npm run build` as the build command, and `dist` as the output directory. No secrets or environment variables are required.

`npm run build` never invokes the existing application or copies its environment files. It copies only this website's explicit public files. Deployment and domain changes have not been performed.

For Squarespace, follow [the integration guide](docs/SQUARESPACE.md). Squarespace is not a general GitHub repository importer; its 7.1 customization route is code blocks, custom CSS and code injection. Integration must be tested inside the actual template before publishing.
